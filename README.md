# STM32 倒立摆控制系统

基于 STM32F103C8（Cortex-M3）的旋转倒立摆/倒立摆控制工程。  
工程通过 ADC 读取摆杆角度、TIM3 编码器接口读取电机位置，并使用角度环 + 位置环串级 PID 控制直流电机，支持自动启摆、位置目标调整和 OLED 实时调试。

## 功能特性

- 摆杆状态检测与自动启摆
- 角度环 PID：稳定摆杆角度
- 位置环 PID：通过编码器位置反馈调节底盘/电机位置
- 串级控制：位置环输出作为角度环目标偏移
- OLED 实时显示 PID 参数、目标值、实际值和输出
- 按键启动/停止、位置目标加减
- LED 状态指示
- ADC 电位器接口，可用于后续参数在线调试
- USART 串口驱动接口

## 硬件平台

| 模块 | MCU 引脚/接口 | 说明 |
|---|---|---|
| MCU | STM32F103C8 | Cortex-M3，主频 72 MHz |
| 角度传感器 | PB0 / ADC1_IN8 | ADC1 读取摆杆角度，范围约 0~4095 |
| 电位器 RP1~RP4 | PA2~PA5 / ADC2_IN2~IN5 | ADC2 读取四个模拟输入 |
| 电机 PWM | PA0 / TIM2_CH1 | PWM 占空比 0~100 |
| 电机方向 | PB12、PB13 | 直流电机方向控制 |
| 编码器 | PA6、PA7 / TIM3 | 编码器接口，累计电机位置 |
| OLED | PB8、PB9 | 软件 I2C OLED |
| K1 | PB10 | 启动/停止 |
| K2 | PB11 | 位置目标 +408 |
| K3 | PA11 | 位置目标 -408 |
| K4 | PA12 | 当前未分配功能 |
| LED | PC13 | 运行状态指示，运行时常亮 |

## 控制逻辑

### 1. 启摆状态机

| 状态 | 含义 |
|---|---|
| `0` | 停止，电机 PWM 为 0 |
| `1` | 检测摆杆状态，判断启摆方向 |
| `21~24` | 向左瞬时驱动启摆 |
| `31~34` | 向右瞬时驱动启摆 |
| `4` | 角度环 + 位置环 PID 控制 |

状态 `1` 每 40 ms 记录一次角度：

- 连续三点位于中心角右侧且中间点较低时，进入向左启摆流程；
- 连续三点位于中心角左侧且中间点较高时，进入向右启摆流程；
- 当连续两次角度均处于中心范围时，清零位置累计和积分项，进入 PID 控制状态 `4`。

启摆驱动由 `START_PWM` 和 `START_TIME` 控制，先施加一个方向脉冲，再反向脉冲，最后回到状态 `1` 检测。

### 2. 串级 PID

- **角度环**：每 5 ms 更新一次  
  实际值为 `AD_GetValue()`，输出直接作用于电机 PWM。
- **位置环**：每 50 ms 更新一次  
  实际值为编码器累计位置，输出作为角度目标偏移：

```c
Angle_PID.Target = CENTER_ANGLE - Position_PID.Out;
```

因此：

- 位置环目标决定摆杆希望保持的位置；
- 角度环负责实时抑制摆杆倾倒；
- 位置环输出限制为 `-100 ~ +100`；
- 电机 PWM 输出限制为 `-100 ~ +100`。

## 默认参数

参数定义位于 `User/main.c`：

| 参数 | 当前值 | 说明 |
|---|---:|---|
| `CENTER_ANGLE` | `2060` | 摆杆直立对应的 ADC 角度 |
| `CENTER_RANGE` | `500` | 允许的角度偏差范围 |
| `START_PWM` | `35` | 启摆脉冲 PWM |
| `START_TIME` | `100` | 启摆脉冲持续时间，单位约为 ms |
| 角度环 `Kp` | `0.3` | 角度比例系数 |
| 角度环 `Ki` | `0.01` | 角度积分系数 |
| 角度环 `Kd` | `0.4` | 角度微分系数 |
| 位置环 `Kp` | `0.4` | 位置比例系数 |
| 位置环 `Ki` | `0` | 当前未使用积分 |
| 位置环 `Kd` | `4` | 位置微分系数 |
| 位置目标步长 | `408` | K2/K3 每次调整量 |
| 位置目标限制 | `-4080 ~ 4080` | 目标位置上下限 |

角度环和位置环的输出范围均为 `-100 ~ 100`。

## 按键操作

| 按键 | 引脚 | 功能 |
|---|---|---|
| K1 | PB10 | 启动/停止。停止时状态回到 `0`，电机停止 |
| K2 | PB11 | 位置目标增加 408 |
| K3 | PA11 | 位置目标减少 408 |
| K4 | PA12 | 预留 |

按键在 `TIM1_UP_IRQHandler()` 中通过 `Key_Tick()` 进行消抖，主循环通过 `Key_GetNum()` 获取按下事件。

## OLED 显示

OLED 使用 6x8 字体分两列显示：

左侧：

- `Angle`
- 角度环 `Kp / Ki / Kd`
- `Tar`：角度目标
- `Ac`：角度 ADC 实际值
- `Out`：角度环输出

右侧：

- `Position`
- 位置环 `Kp / Ki / Kd`
- `Tar`：位置目标
- `Ac`：编码器累计位置
- `Out`：位置环输出

顶部还会显示当前 `Runstate`。

## 构建方法

推荐使用 VSCode + EIDE（Embedded IDE）构建：

1. 打开 `Project.code-workspace`；
2. 安装推荐扩展，主要包括：
   - `cl.eide`
   - `marus25.cortex-debug`
   - `ms-vscode.vscode-serial-monitor`
3. 在 EIDE 中选择 `Target 1`；
4. 执行全量 Rebuild；
5. 成功后生成：

```text
build/Target 1/Project.hex
```

当前 EIDE Target 1 已成功完成全量 Rebuild，源文件和链接文件均已纳入 `.eide/eide.yml`。

### 构建注意事项

- 推荐以 `.eide/eide.yml` 作为源文件列表基准；
- `Project.uvprojx` 是 Keil 工程文件，源文件列表可能未与当前代码完全同步。如果直接使用 Keil 构建出现 `Undefined symbol`，请检查 Keil 工程中的 `Hardware` 源文件是否已添加；
- 本工程使用 STM32 标准外设库和 AC5 工具链；
- Flash 地址为 `0x08000000`，RAM 从 `0x20000000` 开始；
- ST-Link 上传配置位于 `.eide/eide.yml`。

## 调试建议

### 角度标定

1. 将摆杆调整到机械直立位置；
2. 通过 OLED 或串口读取 `Angle`；
3. 将该值写入 `CENTER_ANGLE`；
4. 逐步调整 `CENTER_RANGE`，使其既能判断启摆，又不会把正常摆动误判为失控。

### 启摆调整

如果启摆过慢或无法启动：

- 适当增加 `START_PWM`，通常可从 `30` 调到 `40`；
- 适当调整 `START_TIME`，通常可从 `80` 调到 `120`；
- 调整后需要重新观察左右两个方向的启摆是否对称。

### PID 调整

建议按照以下顺序调整：

1. 先将位置环 `Kp` 设为较小值，确认编码器方向正确；
2. 调整角度环 `Kp`，使摆杆能够快速回到直立位置；
3. 根据静态偏差决定是否增加角度环 `Ki`；
4. 角度环稳定后，再逐步增加位置环 `Kp`；
5. 如位置环响应振荡，谨慎增加位置环 `Kd`，并观察实际值变化；
6. 不建议一开始同时大幅增加 `Kp`、`Ki` 和 `Kd`。

### 编码器方向

控制前请确认电机正转时 `Encoder_Get()` 返回正值。如果方向相反，会导致位置环形成正反馈，表现为越纠偏越偏移。此时应交换编码器 A/B 相，或在读取处对符号取反。

## 已知注意事项

- `AD_GetValue()` 当前采用软件启动转换并阻塞等待 EOC，适合当前 1 ms 控制周期，但如果后续提高控制频率，建议改为中断或 DMA 采样；
- `Position` 当前使用 `int16_t` 累计。长时间运行或编码器分辨率较高时可能接近 16 位范围，建议后续改为 `int32_t`，并同步调整 OLED 格式；
- `Hardware/AD.h` 目前通过 `stm32f10x.h` 间接获得 `uint16_t` 定义，后续建议显式增加 `#include <stdint.h>`；
- 电机启动瞬间、机械限位和电源波动都可能影响角度 ADC 和编码器读数，建议先在电机断电或低占空比情况下验证传感器数据；
- 参数默认值是当前机械结构的调参结果，更换电机、编码器、摆杆长度或供电电压后需要重新标定。
